# TERAC  **Ternary Evidence-driven Reasoning through Arithmetic Competition**  TERAC is an experimental AI architecture focused on efficient computation, adaptive learning, evidence-driven reasoning, and memory management.  ## Core Features  - **Ternary Neural System** — Uses `-1`, `0`, and `+1` for discrete neural representations. - **Binary Neural System** — A pure 1-bit architecture using only `-1` and `+1`. - **Non-Backpropagation Learning** — Explores learning through evidence, parameter competition, rewards, penalties, and causal credit assignment instead of conventional backpropagation. - **Linear Attention** — Explores efficient attention mechanisms without relying on conventional quadratic attention computation. - **Arithmetic Reasoning** — Uses discrete arithmetic operations for computation and reasoning. - **Adaptive Learning** — Supports contextual specialization, error correction, novelty detection, and repetition detection. - **Persistent State** — Maintains internal state and learning history to support continued adaptation. - **Memory Consolidation** — Uses replay, historical information, and multi-timescale learning mechanisms.  ## Three-Tier Learning System  - **Tier 1 — VRAM / Cache:** Fast-access information for active computation and frequently used data. - **Tier 2 — RAM:** Working memory and intermediate learning data. - **Tier 3 — SSD / NVMe / HDD:** Persistent storage and background learning.  The system is designed to coordinate learning, execution, caching, and storage across different hardware resources.  ## Design Goals  - Reduce memory and computational requirements. - Explore alternatives to gradient-based training. - Improve learning efficiency and adaptability. - Support different neural representations. - Investigate scalable memory and attention mechanisms.  ## Status  TERAC is an experimental architecture under active development. Features, implementations, and performance may change.  ## License  See the repository for licensing and usage terms.  ---  **TERAC — Rethinking how AI computes, learns, and reasons.**
